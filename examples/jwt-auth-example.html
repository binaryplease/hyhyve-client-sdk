🔐 JWT Auth

HyHyve SDK Example

This example demonstrates secure JWT-based authentication with the HyHyve SDK.

🔑 How JWT Auth Works

  • Your backend signs a JWT with your API key
  • Frontend receives the token securely
  • Token is passed to HyHyve for authentication
  • User is authenticated automatically

🚀 Quick Start

Start the backend server first:

cd examples && node server.js

Make sure you have a .env file with HYHYVE_API_KEY and HYHYVE_CLIENT_ID

⚠️ Important

This example uses a local backend server. In production:

  • Create and sign JWTs with your API key
  • NEVER expose your API key to clients
  • Implement proper user authentication
  • Use short token expiry times (5-15 min)

Backend Implementation Example (Node.js/Express)

import express from 'express';
import jwt from 'jsonwebtoken';

const app = express();

// Middleware to authenticate user session
function authenticateUser(req, res, next) {
  // Your session/auth logic here
  if (!req.session?.userId) {
    return res.status(401).json({ error: 'Unauthorized' });
  }
  next();
}

// Endpoint to generate HyHyve JWT token
app.get('/api/hyhyve-token', authenticateUser, async (req, res) => {
  const user = await getUserById(req.session.userId);
  
  const payload = {
    clientReferenceId: user.id,
    profile: {
      name: user.name,
      color: '#007bff',
      picture: user.avatarUrl || '',
      socials: user.socialLinks || [],
      headline: user.title || '',
      emoji: '👋',
      status: 'Available'
    }
  };
  
  // Sign with your HyHyve API key (NEVER expose this!)
  const token = jwt.sign(payload, process.env.HYHYVE_API_KEY!, {
    algorithm: 'HS256',
    expiresIn: '5m' // Short expiry recommended
  });
  
  res.json({
    token,
    clientId: process.env.HYHYVE_CLIENT_ID
  });
});

app.listen(3000, () => {
  console.log('Server running on http://localhost:3000');
});
